# 模拟实验启用前检查

本工具只读检查，不部署、不重启、不创建目标数据库、不修改实验参数，也不授予真实交易权限。预检通过只表示已检查的工程条件满足，不等于真实盘中验收或盈利验证通过。

## 配置来源

模拟账户使用 `V2_PAPER_SESSION_CONFIG` 指向的 JSON，格式见本目录 `README.md`。

盘口采集兼容原有 `V2_BOOK_CAPTURE_PATH`。需要调整容量时，可以设置 `V2_BOOK_CAPTURE_CONFIG` 指向显式 JSON，例如：

```json
{
  "schema_version": 1,
  "path": "/data/futu_trade_data/research/capture.sqlite",
  "max_stocks": 4,
  "sample_interval_seconds": 0.5,
  "max_bytes": 268435456,
  "min_free_bytes": 268435456
}
```

这是容量格式示例，不是已启用配置；其他字段沿用 `BookCaptureConfig` 默认值。若同时设置文件配置和旧路径变量，两者必须指向相同路径，否则拒绝装配采集器。未设置两者时保持关闭。预检应读取与运行时完全相同的配置文件。

## 流程

1. 明确目标运行版本、交易主库、独立归档与模拟账本路径。优先有预算的数据盘，目录提前由运维创建；预检不会创建目录或探测性写文件。
2. 审核普通股名单、交易时段、费用假设和研究参数。复用已有信号不代表新退出参数已验证；人工审核标志只记录声明，不会自动核实外部资料。
3. 进行有上限的合成容量检查，得到空间估算来源。它不调用富途、不读生产数据、不产生真实买卖信号。
4. 在实际目标主机运行只读预检。结果为 0 才说明本次预检无阻塞；仍需独立授权部署/启用及实际盘中验收。

```bash
bash scripts/run_paper_capacity_benchmark.sh \
  --directory /data/futu_trade_data/research \
  --records 4000 --stocks 3 \
  --output /data/futu_trade_data/research/capacity-report.json
```

范围固定为 100–10000 条记录、1–8 只合成股票，最多 180 秒处理预算，至少 1 GiB 可用空间。使用指定目录下新建的临时子目录，验证其位置后由临时目录管理器清理。已有报告拒绝覆盖。报告仅保留统计，不保留模拟数据库作为真实行情证据。

生产退出模式须额外指定 `--exit-policy PRODUCTION_RULES --feature-interval 5`（5 秒仅为格式示例，须与实际输入频率复核）。该模式的负载包含特征输入、独立持仓分析、资金记忆状态持久化与账户重读，报告另列特征命令数量和耗时。预检拒绝用旧 ATR 容量报告批准生产退出模式，并按指定频率另计特征命令预算；不因此保证真实推送频率或最坏写入量。

```bash
bash scripts/run_paper_readiness_check.sh \
  --config /data/futu_trade_data/research/paper.json \
  --capture-config /data/futu_trade_data/research/capture.json \
  --trading-db /data/futu_trade_data/trade.db \
  --strategy-version TARGET_RUNNING_STRATEGY_VERSION \
  --capacity-report /data/futu_trade_data/research/capacity-report.json \
  --protected-stocks 1 --system-path / \
  --reviewed-schedule --reviewed-securities --reviewed-costs --reviewed-parameters
```

命令中的版本及保护席位必须用目标环境实际值；保护席位按与实验名单不重叠保守计数。未完成审核时不要传对应 `--reviewed-*`。配置未提供的时间不能按工作日猜补。也可用 `--capture-path` 检查原有默认采集配置，它与 `--capture-config` 互斥。

退出码：`0` 为预检无阻塞；`2` 为配置可解析但存在明确阻塞；`1` 为读取或输入错误。`execution_allowed` 始终为 `false`。`--at` 仅用于可复现的指定时点研究；实际启用检查应省略，以目标主机当前时间为准。

## 检查内容

- 三个数据库路径隔离，检查同路径、软链接及硬链接。
- 规则版本一致；未来有效时段与入场窗口存在；人工审核项齐全。
- 股票名单与真实持仓保护席位不超采集上限。
- 目标目录和文件权限、数据库身份、已有记录和文件大小；查询为只读且有执行时限。
- 模拟账本配置不可变；活跃/异常运行或已有模拟风险敞口需要复核，不自动续跑。
- 系统盘至少 2 GiB 可用空间。这是工程保留基线，不代表足以容纳所有应用日志。
- 同一文件系统的可用空间只算一次，同时预留归档、账本、临时回滚日志及配置保留空间。
- 用剩余配置时段、采样间隔、股票上限和声明的每条空间估算记录/命令及文件预算。额外命令预算为显式假设，不是信号数预测。

容量估算采用本次合成平均占用的两倍作为预算假设，不是最坏情况保证。采集器在配置时段外也可能收到行情，重连、非正常时段推送、更多信号、不同价格字段长度、部分成交数量及增长后的账本都会影响实际占用。真实负载验收仍不可省略。

## 2026-09-23 本地观测

以下为原 ATR 模式的历史观测，不适用于新增的生产退出模式；后者须重新测量，不能沿用下列容量结论。

Windows 本机 4000 条合成盘口、3 个模拟持仓，顺序处理约 19.86 秒，约 201 条/秒；纸面命令处理（含账户重读）95 分位约 8.95 毫秒；归档批次 95 分位约 18.51 毫秒。盘口数据库约 2.46 MiB、模拟账本约 2.47 MiB。不是服务器并发性能或实时端到端延迟。

据此形成的两倍平均占用假设为：盘口每条 1289 字节、模拟命令每条 1296 字节，额外预留 1000 条命令。常规 5.5 小时示例的估算如下，时段仅用于容量计算：

| 配置示例 | 盘口归档估算 | 模拟账本估算 | 说明 |
|---|---:|---:|---|
| 8 只采集、8 只模拟、500 毫秒 | 389 MiB | 393 MiB | 超过各 256 MiB 文件预算，模拟命令也超过 25 万 |
| 3 只采集、3 只模拟、500 毫秒 | 146 MiB | 148 MiB | 尚未计入其他持仓保护席位 |
| 4 只采集、3 只模拟、500 毫秒 | 195 MiB | 148 MiB | 仅为含一个额外保护席位的容量示例，不保证额度与覆盖 |

首次服务器只读核查时系统盘仅约 1.4GB 可用，未达到上述保留基线；数据盘约 15GB 可用。服务器代码为 `8a4068e`，未部署这些模拟功能。

随后经用户明确授权，仅删除另一个项目 `ai_image` 的 5 个未使用 8 月镜像：后端 `5a65a47`、前后端 `6bf8880`、前后端 `rollback-82b3490`。使用非强制精确删除，未执行全局清理。系统盘使用率从 98% 降至 87%，可用约 7.9GB；数据盘仍约 15GB 可用。当前镜像、全部 9 月版本、数据库卷与文件备份均保留；交易系统三服务和另一个项目四容器保持运行，没有重启或部署。

空间阻塞已缓解，但不是完整预检通过：实验名单、保护席位、未来交易时段、费用和参数仍待审核；盘口和账本容量须按冻结配置重新计算。未启用模拟或真实下单。

本轮本地回归：546 项测试、24 个子测试通过，两个入口脚本语法与差异检查通过。只读探测包含错误数据库、硬链接隔离、异常运行、超大状态、缺失路径和空间预算用例。

## 生产退出模式补测

2026-09-23 本机 Windows 合成测试：4000 条盘口、3 个持仓、每股每 5 秒特征评估，共处理 402 条特征命令；约 17.72 秒。盘口命令 95 分位约 5.69 毫秒，特征命令约 6.56 毫秒，独立纸面账本约 3.96 MiB。两倍平均命令占用假设为 1886 字节，高于旧模式的 1296 字节。

这只是固定价格、约 11 分钟合成路径的本机顺序负载，不验证服务器并发、完整交易日、真实信号或盈利能力。报告为 `backtest_results/paper-production-capacity-20260923.json`；启用仍需目标服务器按冻结配置重新测量和审核，不能直接沿用本机性能数字。
