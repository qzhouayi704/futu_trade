# 本地盘中模拟实验

这是独立的纸面账户，不是富途模拟账户，更不是实盘执行器。默认关闭，未配置生产参数，未部署或开启真实行情验收。原有 V2 正式提醒条件、微信通知和真实持仓处理不变。

## 已接通的链路

```text
已持久化的确认事件 -> 独立研究计划 -> 风险定仓与现金预留
                                              |
富途采样盘口 -> 独立归档提交 -> 严格检查 -> 模拟买入/部分成交
                                              |
                                失效价或持有期限 -> 待退出
                                              |
                              后续有效买盘 -> 模拟卖出与费用账本
```

研究计划仅接受指定规则版本、指定策略来源、明确普通股名单内且 `alert_eligible=true` 的确认事件。影子确认不自动提升为正式买点。没有每手股数来源、有效 ATR、当时价格或交易日程，都会记录拒绝原因，不使用默认每手数量补齐。

研究计划保存在独立纸面账本；线上决策的 `entry_plan` 和真实执行许可没有被改写。不要把实验计划误认为实盘订单资格。

计划按实验参数生成，不是已验证的最优策略：

- 入场下限 = 确认时价格 × (1 - 允许回踩比例)。
- 入场上限 = 确认时价格 × (1 + 最大追价比例)。
- 失效距离 = max(最小距离, ATR 百分比 × ATR 倍数)。超过最大允许距离则拒绝，不压窄止损强行买入。
- 到期 = 明确日程中当日最后一个区间结束前的指定秒数。
- 入场有效期不跨越当前连续交易区间或退出期限。
- 同一实验、同一股票、同一香港日期最多创建一次计划；不自动加仓或换仓。

信号失效会撤销剩余模拟买量，已成交部分仍按原计划退出。退出触发后，需要后续有效盘口才能成交；没有行情就保留 `EXIT_PENDING`，不会虚构收盘成交。

## 配置与启动

必须先配置独立盘口归档（`V2_BOOK_CAPTURE_PATH` 或 `V2_BOOK_CAPTURE_CONFIG`），再通过 `V2_PAPER_SESSION_CONFIG` 指向一个绝对路径 JSON 文件。两个数据库路径必须不同，父目录提前存在。后端仍由仓库现有 `.sh` 脚本启停；本模块没有券商下单入口。

启用前先执行本目录 `PREFLIGHT.md` 的只读预检与容量检查。默认预算并不保证覆盖 8 只股票的完整交易日，不能直接把文档示例作为已审核配置。

配置结构如下。数值仅演示字段格式，日期刻意使用历史测试日，不能直接用于今天的实验，也不构成参数推荐：

```json

  "account_id": "paper:reviewed-experiment",

    "stock_codes": ["HK.00100"],

```

未指定的 `PaperPolicy` 风险预算沿用已有模拟基线：单计划权益风险 0.25%、组合 0.75%、单股 10%、现金保留 30%、最多 3 个活动计划、展示数量参与率 10%、至少 1 秒延迟、盘口最长 3 秒。费用是显式研究假设，不是已审核的香港税费或用户券商账单。

日程是显式输入，程序只验证时区、区间及不重叠，不能证明日程来源真实正确；节假日、半日市、特殊暂停交易需在启用前审核。普通股名单同样须预先核实，不按股票代码猜资产类别。新增时间范围或改参数应使用新实验账本，旧配置不可覆盖。

默认队列 1,024、命令预算 250,000、账本主文件上限 256 MiB、至少保留 256 MiB 空间。SQLite 临时日志另需空间。重复命令也消耗保守的运行工作预算；这些上限不保证高频采样可以覆盖完整交易日，达到上限会停止，不自动删历史或扩盘。

## 查看结果

运行状态的 `paper_session` 字段显示队列、计划、成交、活动股票、估算权益、过期持仓估值和错误。金额以十进制字符串返回。

本地代码已新增 V2 工作台的“模拟账本”标签及 `GET /api/v2/paper/ledger`。仅读取当前配置指定的独立账本，不接受请求指定文件路径，不提供下单、启用或参数修改接口。未启用时显示明确空态，不创建数据库，不用零收益代替缺失数据。

- 模拟计划：最多 100 个，活动计划优先、同类按批准时间从新到旧；同时显示总数。展示买入范围、失效价、待买/已买/已卖/持有数量及退出期限。
- 模拟成交：最近 50 笔，展示股票、方向、数量、价格及费用，均为近似模拟结果。
- 信号处理：独立查询最近 50 条信号，不会被更高频的盘口记录挤出；拒绝与失效原因以中文显示。
- 已平仓净盈亏仅来自已经买入并全部卖出的计划。没有平仓样本时显示 `--`，不展示未经验证的胜率。
- 报告时估算权益显示账本时间和读取时间；过期持仓有警告。停止或启动失败不代表模拟持仓已经卖出，已有账本仍可读。账本未关闭记录不能单独证明工作线程正在运行。
- 只读查询最多 5 秒执行预算，账户 JSON 最多 4 MiB、配置及单条命令 JSON 最多 256 KiB；超限明确报错，不截断后伪装完整结果。同实例请求合并、短暂复用 2 秒；网页只在账本视图挂载时每 15 秒请求，超时 10 秒且不叠加自动重试。

当前仅查看已配置实验，不支持网页切换历史账本或跨实验绩效汇总。退出页面停止轮询；读取失败时保留已有结果但明确标记为上次读取数据。

只读命令无需启动 OpenD 或应用：

```bash
bash scripts/run_paper_session_check.sh --db /absolute/path/research.sqlite
```

输出包括冻结配置、运行记录、订单、最近 50 笔成交和最近 50 条输入/处理结果。`closed_order_net_pnl` 仅统计完全卖出的订单并扣除模拟费用；`marked_equity` 是持仓估值，需同时查看 `stale_position_codes`，不是已实现收益或最终净值。`OPEN_OR_UNCLEAN` 不能证明进程仍运行。

## 故障与限制

- 单个账本只允许一个运行者。配置变化、未正常关闭、已标记错误、重启时仍有活动订单/持仓，均拒绝自动继续，要求复核；不要通过清空运行记录强行恢复。
- 队列溢出、归档丢失、连接切换、决策流丢失或写盘失败，停止实验并留存错误。保留未退出仓位不等于已经平仓。
- 输入队列不是持久消息队列。故障或停止时未处理输入会计为缺口，不宣称跨故障无损续跑；账本原子保存已处理输入、结果和账户状态。
- 正常停止也不代表整个行情区间完整。盘口在采集期间独立归档，但不自动回填停止期间的模拟成交。
- 盘口目标依次为真实持仓/订单、模拟活动股票、实验名单、其他确认候选，受共享额度和采样上限约束；入选目标不保证订阅成功或有可成交盘口。
- 富途服务器接收时间不是交易所时间。采样、显示数量参与率、延迟、费用和 ATR 退出均是研究模型；未校验排队位置、完整深度、真实成交冲击或合法报价档位，不可接实盘。
- 本轮不接账户级日亏损熔断、自动轮换/加仓、公司行动处理及可无损恢复的执行网关。实盘前必须另行验证和授权。

相关单元测试和 Mock 端到端测试覆盖幂等、价格时效、确认前盘口、午休/半日示例、部分成交、失效撤单、无行情到期、写盘失败、队列溢出和正常业务隔离。通过工程测试不代表策略有正收益。
