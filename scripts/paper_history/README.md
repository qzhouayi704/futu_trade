# 历史信号与模拟账户研究

本工具只读生产数据、离线运行，没有券商发单路径。它评估已记录的确认事件，不重新计算历史策略信号，也不意味着新版策略已完成回测。

## 两种模式

1. 默认执行条件检查：每手股数、可执行计划、历史盘口、后续完整分钟是否存在。缺失证据不能用假定值偷偷补齐。
2. 显式分钟压力模拟：以真实分钟区间为研究输入，但假定每手股数、资金、费率、滑点和日内退出政策。复用 `PaperEngine` 的资金预留、风险定仓、部分成交和退出等待；不是历史盘口撮合或真实账户收益。

分钟压力模拟以完整分钟的最高价加滑点作为合成卖价、最低价减滑点作为合成买价，以分钟总成交量乘参与比例近似容量。它有意采用不利价格，但没有队列、价位档位或真实可售数量证据，不能承诺是实际收益的保守下界。合成输入仅存在于本研究模块，不能传给实盘适配器。

只允许使用操作时间之后开始的完整分钟。分钟假定于结束后 1 秒可用；信号所在分钟不能用于成交，止损、止盈、期限退出触发后必须等待后续完整分钟，不能在同一分钟最高价卖出。高低点先后未知时，先执行风险保护判断。分钟均价只作数据校验，不当作收盘价或可成交价。

## 数据导出

导出涉及生产信号和风控记录，应先得到数据所有者对目标目录和范围的授权。服务器数据库必须使用部署文档核实的路径，不使用过期的本地数据库。

```bash
python scripts/paper_history/export.py \
  --db /data/futu_trade_data/trade.db \
  --start 2026-09-14 --end 2026-09-22
```

输出 JSON 到标准输出。脚本可经 SSH 标准输入运行，无需安装或修改服务器代码。`--end` 不包含该日；单次最多 31 个自然日、4000 个确认事件、50 万条分钟记录，查询总预算 60 秒。只读 URI、`query_only` 和一致性事务共同约束数据库访问；不会读取账户凭据、余额或真实订单明细。只提取 BUY 意向的风险审核状态及微信是否送达，不导出完整意向或消息正文。

分钟范围包括所有发出确认的股票在指定日期内的记录，以保留跨日待退出仓位可用的数据。不会只挑涨幅高的股票。归档完成时间并不证明每只股票全天连续覆盖。

## 运行

```bash
bash scripts/run_signal_history.sh \
  --input backtest_results/paper-history.json \
  --output backtest_results/history-readiness.json
```

以下是假设情景，不是已经确认的真实每手股数或券商费用：

```bash
bash scripts/run_signal_history.sh \
  --input backtest_results/paper-history.json \
  --output backtest_results/history-stress-lot100-fee15bp.json \
  --allow-minute-stress --assumed-lot-size 100 \
  --initial-cash 100000 --fee-rate 0.0015 --minimum-fee 10 --slippage-bps 5
```

输出已存在时拒绝覆盖。每份报告保留输入 SHA256、日期、导出时间、场景版本及全部假设。重复输入与参数应得到相同模拟结果。

## 口径

- `delivered`：正式确认且风险通过、微信已送达。
- `eligible`：允许正式提醒的确认，包含最终未发送或风控拒绝的事件；不等于有权限真实下单。
- `shadow`：影子确认，不与正式确认混算。三个账户分别运行，`delivered` 与 `eligible` 存在重叠，不可相加。
- 各组同一股票同一天只取首个收到的确认。按代码与名称启发式排除 ETF 等产品，并非完整历史证券主数据。
- 研究基线：信号价上下 1% 限价区间、10 分钟有效期、参考价下方 3% 止损、上方 5% 止盈、15:50 触发退出。均为假设，未选优、不是现行系统退出规则的完整复制。
- 使用纸面账户默认的单笔/组合风险、单股比例、最多 3 仓和现金保留约束。估值允许 120 秒过期仅属于分钟研究情景，未修改盘口回放或线上参数。
- 时段按 09:30–12:00、13:00–16:00 假定常规交易日；不能用于半日市和未验证日历的收益结论。跨日拆并股、复权、公司行动及加换仓尚未建模。
- 不补齐缺失分钟、不强行收盘清仓；未卖仓位继续占用现金和仓位额度。过期持仓估值存在时，组合收益百分比返回空值，待卖仓位保留。
- `closed_win_rate_pct`、收益分布只统计已完整退出的模拟交易。必须同时看未成交、未退出、行情缺口；不能只展示赢率或把候选/确认数量当交易次数。
- `marked_net_pnl_not_fully_realized` 已扣发生的模拟费用，但不包含仍持有股票未来卖出成本。报告均为研究结果，不是盈利承诺。
